# Whiteboard App

The **Whiteboard App** is a simple drawing application built using Python and the Tkinter library. It allows users to draw on a canvas using a customizable brush size and color. The application also provides options to clear the canvas and choose a new color for drawing.

## Features

* Draw on a canvas using a brush
* Change brush color using a color picker
* Adjust brush size with a slider
* Clear the entire canvas

## Installation

### Prerequisites

* Python 3.x
* Tkinter library (usually included with Python)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Hritik-0-7/whiteboard.git
   ```
2. Navigate to the project directory:

   ```bash
   cd whiteboard-app
   ```
3. Run the application:

   ```bash
   python whiteboard.py
   ```

## Usage

* Hold the left mouse button and move the mouse to draw on the canvas.
* Click the **Clear** button to erase the canvas.
* Click the **Color** button to select a drawing color.
* Use the **Brush Size** slider to adjust the brush thickness.
